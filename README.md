# 青鸟 · Bluebird v0.1.2

署名：克克姐&奶盖&鱼仔

SillyTavern 小手机扩展：角色在剧情里主动给你发消息，手机里聊过的内容自然回到剧情。

## 当前进度：第一段 · 骨架

已做：

- 青鸟入口：默认可拖动的悬浮球，可切换为收进酒馆魔法棒菜单；未读角标机制已留好，目前消息功能尚未开放
- 手机全屏面板，适配动态视口高度与四边安全区；打开时隔离背后的酒馆控件，关闭时恢复
- 消息、通讯录、设置三页，前两页暂时是空状态
- 配色：跟随系统、日间、夜间三种，颜色是插件自己的，不跟酒馆主题
- 设置页：正文消息提醒标注「待开放」，暂时不可切换，保留原有设置值
- 扩展抽屉里：启用开关、入口显示方式、打开青鸟；青鸟面板的设置页也能切换入口

还没做：消息和楼层（第二段）、角色主动发（第三段）、你主动聊（第四段）、NPC（第五段）、语音（第六段）。

## v0.1.2 更新

- 去掉输入框上方单独占一行的青鸟按钮。
- 默认显示 52px 悬浮球，可拖动、记住位置；旋转屏幕或视口变化后保持在可见范围内。
- 在「青鸟 → 设置 → 入口显示方式」或「酒馆扩展设置 → 青鸟 → 入口显示方式」选择悬浮球 / 收进魔法棒，立即生效。
- 拖动悬浮球不会误触打开面板；切换模式和停用再启用时保留未读角标。

## v0.1.1 更新

- 当前只按手机端设计，统一全屏布局。
- 收起面板时拦截 Esc，不再把关闭按键传给酒馆；中文输入法组字时不处理 Esc。
- 全屏面板隔离背景控件，限制 Tab 焦点范围；关闭后恢复之前的焦点和背景状态。
- 输入栏或扩展设置容器尚未出现时自动补挂，完成后停止观察；兼容新旧事件字段名。
- 设置读取排除数组，并校验两个开关的布尔类型和配色选项。
- 未开放功能明确标注，入口按钮栏独占一行。

已进行 JavaScript 语法检查和关键逻辑的隔离测试。真实 iPhone、酒馆主题和快速回复扩展的布局兼容仍需实际安装确认。

## 从仓库安装（推荐）

在酒馆的「扩展 → 安装扩展」中填入：

```text
https://github.com/phyllis-0612/st-bluebird
```

安装后刷新酒馆，默认在屏幕右下区域显示青鸟悬浮球。可在设置里切换为魔法棒菜单入口。当前版本只有界面、页面切换与配色，消息收发和剧情联动将在后续版本开放。

## 手动安装

把整个 `st-bluebird` 目录放进：

```
SillyTavern/public/scripts/extensions/third-party/st-bluebird/
```

已有 v0.1.0 时，用本包内 `st-bluebird` 文件夹里的文件覆盖原插件文件，然后刷新。无须删除原设置。

## 给奶盖：需要真机确认的地方

1. 悬浮球点击、拖动、位置记忆与屏幕旋转；切到魔法棒后只在魔法棒菜单显示入口，输入栏不新增一行。
2. 目标酒馆版本的 `SillyTavern.getContext()` 字段：`extensionSettings`、`saveSettingsDebounced`、`eventSource`、`eventTypes` 或 `event_types`、`characters`、`characterId`、`groups`、`groupId`。
3. 手机全屏时 `z-index: 9000` 能不能压住酒馆顶栏和各个抽屉。
4. 酒馆全局样式或美化主题有没有压过面板里的按钮、单选、开关。面板样式都以 `#bluebird-panel` 开头，理论上压得住。
5. iOS 刘海和底部横条：全屏时用了 safe-area，确认内容不被挡。
