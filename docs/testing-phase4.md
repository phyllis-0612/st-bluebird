# 第四段 · 手机实测（v0.4.0）

先在酒馆更新青鸟并刷新，确认青鸟设置最下方版本为 0.4.0。建议使用可随时删除的测试聊天。

## 1. 发消息与回复

打开青鸟 → 通讯录 → 当前角色，发「我到家了，你在做什么？」。

应立即出现你的消息，随后显示「对方正在输入」，等接口返回后出现角色回复。连着发两句话，默认最后一句后等待 1.5 秒再合并回复。接口慢时等待时间会更长。

手机模型先留空测试现有连接。需要 Flash 时，在「手机回复模型」填当前连接提供的准确模型 ID；不重复填写 key，也不会切换主线模型。模型报错时清空该字段重试。

点击 + 测语音、转账、图片、定位。语音目前填文字，图片填画面描述，真实声音在第六段接入。

## 2. 主线接上手机聊天

在手机里告诉角色一个容易检查的新事实，例如「我买了一把红色雨伞，放在门口」。等她回复，然后收起青鸟，在酒馆正常发送下一句生成剧情。

应有两种结果：主线能接上手机里聊过的事；手机会话里的「下一轮剧情后保存到楼层」变成实际楼层号。编辑新回复的前一楼，末尾应有 `bb-phone source="phone"` 的隐藏块。前一楼是你的消息也正常。

刷新后手机聊天还在；删除落楼的那一楼后，这批手机消息一起消失。查看原文时不要只看格式化后的正文。

## 3. 重 roll、取消与失败

手机聊完后直接重 roll，暂存会保留到成功生成并落楼。生成途中点停止或遇到接口错误，手机内容应仍在暂存区；下次成功生成才落楼。

手机回复失败时点击「重试回复」，不需要重新发送用户消息。刷新后若仍有待回复消息，也会显示重试入口。旧聊天请求返回时不能出现在新聊天里。

若你在角色回复期间开始主线、编辑或切版本，青鸟会保留消息并停止采用旧回复，可在稳定后重试。

## 4. 记忆与手机界面

装了结绳时，问角色一个有效总结中有、近期正文里没有的事实，确认回复能使用总结和脉络；没有有效总结时只读取配置的近期剧情。正文默认取 content，状态栏标签在设置里排除。

重点看手机键盘弹出后的输入栏、+ 表单和发送按钮是否遮挡。输入到一半时等回复到达，草稿应保留；语音卡片点击展开文字的交互应继续正常。

## 当前验证范围

57 项自动检查通过，包含协议、保存、模型请求隔离、连发、暂存快照、停止/失败、流式事件顺序、结绳两种模式、输入草稿和附件交互。当前执行环境缺少浏览器程序，真实手机布局、iOS 键盘、实际 API 和酒馆保存仍需以上实测。
