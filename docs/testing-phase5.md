# 第五段 NPC 真机实测

更新扩展并刷新酒馆，确认设置页版本是 0.5.0。选一张有主世界书和附加世界书、其中同时有人物及地点/组织条目的角色卡。

1. 打开「青鸟 → 通讯录 → 从角色卡和绑定世界书提取」。若书较大，会分批调用当前酒馆连接；设置了手机回复模型则使用那个模型。确认能看到主书及附加书来源，地点和组织默认未勾；选中人物，调好主动程度，点「加入通讯录」。
2. 打开 NPC 会话，连发两条手机消息。发送时不请求模型；点「让对方回复」才请求一次。编辑对应世界书条目后再发一次，确认新的内容能影响回复。
3. 在主线制作一段 NPC 未在场的秘密，末尾有 `<bb-present>无</bb-present>` 或只列其他角色；随后制作一段 NPC 在场剧情，末尾列其通讯录原名。再与 NPC 聊天，问未在场秘密和在场事件，确认不知前者且记得后者。若上一楼已经明确列 NPC，在下一个无 `bb-present` 的楼层仍算在场；`未知` 不算在场。
4. 在通讯录把 NPC 主动程度改为「黏人」，让 NPC 离场，再推进主线（确保手机冷却已结束）。检查 NPC 是否能按原名发送 `<bb-phone>` 消息；同场时不应发。主动消息由模型按规则决定，可能需要给合适的剧情时机。
5. 删除或改名原世界书条目后重试手机回复，应提示重新提取，已经发出的用户消息仍在暂存区。

如不符合，记录酒馆版本、角色卡主/附加世界书名称、提取候选列表、对应主线楼层末尾的 `bb-present`、手机回复表现。不必贴含敏感信息的整份世界书。
