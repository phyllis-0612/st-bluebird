# 第六段语音与 API 预设实测

更新扩展并刷新酒馆，确认青鸟设置页版本为 0.6.0。

1. **纯文字兜底**：不用配置语音 Key 和音色，打开语音消息，点播放图标应展开文字，不应请求合成；关闭「语音消息模式」时直接显示文字。
2. **梨园共用 Key**：先在梨园填好 MiniMax 或 ElevenLabs 的 Key、地址和模型。在青鸟通讯录给某位联系人选择同一服务，刷新音色列表或选择梨园已有音色，保存。青鸟自己的语音 Key 留空，设置页应显示「当前使用梨园」。让该联系人发一条语音，点一次播放，确认能听到、文字展开。
3. **缓存**：同一条语音播放完后再点一次播放，应直接播放已缓存音频，不重复发合成请求。改音色或模型后应重新合成。同一时间点另一条语音，前一条应停止。手机退出页面后再次进入，缓存仍应可用。
4. **独立语音 Key**：若梨园没装或没有对应服务 Key，在青鸟设置填自己的 Key、地址和模型，通讯录指定音色后重试。MiniMax 可手填 voice_id；ElevenLabs 可用「刷新音色列表」拉账号音色。填错 Key 时会提示合成或音色列表错误，文字仍可看。
5. **API 预设**：青鸟设置 → API 预设 → 新建，填写 OpenAI 兼容接口的地址、Key 和模型 ID（也可点「获取模型列表」）。保存后，手机连发两条再点「让对方回复」，确认只发一次青鸟请求；NPC 提取也使用该预设。切回「跟随酒馆当前连接」后，再试一条，确认走原酒馆连接，主线模型设置没有改变。
6. **iOS**：在 iPhone 上点语音播放，确认第一次点击就有声音、切后台再回来仍可点播。若 ElevenLabs 请求报跨域错误，请保留浏览器控制台错误和接口域名（不要发 Key）。

接口按梨园实现使用 MiniMax `/v1/t2a_v2` 和 ElevenLabs `/v1/text-to-speech/{voice_id}`；语音合成会产生服务商用量。两家音色列表跨域与具体账号权限仍以实际连接为准。
